10-Thread Concurrency Simulation & ACID Integrity

Figure 11.2: Live Interactive SQL Console executing multi-table joins against MySQL engine

To prove thread safety, the system provides a 10-thread concurrency test simulating 10 simultaneous booking attempts for the same venue and date. Exactly 1 thread succeeds (ACID commit), while 9 threads are blocked by constraint validation (VenueUnavailableException).
